OLEACHRON — Minimum Asset System

1) oleachron-logo-horizontal-light-transparent.png
Use for: website header on light backgrounds, landing pages, login pages with light background, PDFs, email signatures, printed light materials.
Notes: This is the main primary logo.

2) oleachron-logo-horizontal-dark-transparent.png
Use for: website header on dark/olive backgrounds, dark hero sections, dark social covers, dark promotional graphics.
Notes: Use when the background is dark and the light version is needed for contrast.

3) oleachron-app-icon-light.png
Use for: app stores, iOS/Android app icon reference, PWA icon reference on light style systems.
Notes: Best for mockups, decks, and when the surrounding UI is light.

4) oleachron-app-icon-dark.png
Use for: app stores, mobile icon previews, splash/mockup references, dark UI systems.
Notes: Usually stronger and more premium-looking.

5) oleachron-favicon-mark.png
Use for: favicon, browser tab icon, bookmarks, tiny navigation/icon use, compact brand mark.
Notes: This is the simplified micro-mark. Best at small sizes.

6) oleachron-brand-usage-guide.png
Use for: giving Cursor/design/dev a one-page visual guide.
Notes: This image shows the minimum system and placement examples.

Recommended placement by product area
- Website header: use oleachron-logo-horizontal-light-transparent.png on light backgrounds.
- Website header (dark section): use oleachron-logo-horizontal-dark-transparent.png.
- Login screen: center the icon above the OLEACHRON wordmark; use the guide image as layout reference.
- Mobile app icon: use oleachron-app-icon-dark.png or oleachron-app-icon-light.png.
- Splash screen: center the logo/icon on a clean background; dark version is preferred.
- Browser favicon: use oleachron-favicon-mark.png.

Design direction to keep
- New-age + classic.
- Clean and premium, not busy.
- Olive / sage / cream / muted gold palette.
- Prefer more whitespace and fewer decorative details.
- Keep the infinity-root idea, but in a simpler form.
