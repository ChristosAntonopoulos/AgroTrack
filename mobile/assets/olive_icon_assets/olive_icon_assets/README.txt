Olive icon asset pack

Folders:
- source/: original upload and cropped master
- app/: standard mobile app icon PNG sizes
- web/: favicon and web app icon sizes in PNG, ICO, and WEBP

Suggested usage:
- App Store / Play Store listing: app/app-store-1024.png
- Android app icon: app/android-192.png or app/android-512.png
- iOS app icon: app/ios-180.png (plus other sizes if needed)
- Website favicon: web/favicon.ico
- PWA / manifest icons: web/web-icon-192x192.png and web/web-icon-512x512.png
- Apple touch icon: web/apple-touch-icon-180x180.png
