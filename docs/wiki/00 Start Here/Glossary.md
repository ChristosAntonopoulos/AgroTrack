## Purpose

Common terms used across AgroTrack. Add new entries as the language evolves.

## Terms

| Term | Definition |
|---|---|
| Field | A defined piece of land managed in AgroTrack. Has size, location, crop and owner. |
| Owner | The person or organisation that owns the field. May or may not work the field themselves. |
| Producer | The person or team that does the work on the field. May manage many fields for many owners. |
| Agronomist | An expert who advises on crop choice, treatment, lifecycle and best practice. |
| Organisation | A group of users that share access to fields and data (e.g. a farm, a co-op, a producer company). |
| Crop | What is grown on a field — e.g. olives, grapes, wheat. |
| Crop Cycle | One full season or production cycle of a crop on a specific field. |
| Lifecycle Stage | A defined phase within a crop cycle (e.g. dormant, flowering, fruit set, harvest). |
| Field Task | A specific job to do on a field (e.g. prune, irrigate, treat, harvest). |
| Field Activity | A record of something that happened on a field (e.g. "irrigated 4 hours on 12 May"). |
| Expense | A cost recorded against a field, cycle or task. |
| Document | A file attached to a field, cycle or activity (e.g. receipt, photo, certificate). |
| MVP | Minimum Viable Product — the smallest version we can ship and learn from. |
| Sprint | A fixed period (usually 2 weeks) where the team commits to a set of work. |
| Epic / Feature / PBI / Task | Azure DevOps work item hierarchy. See `06 Scrum and Delivery/Work Item Structure`. |
| DoR / DoD | Definition of Ready / Definition of Done. |
| Pilot | A real customer running a real workflow on AgroTrack, with our active support. |
| LOI | Letter of Intent — non-binding signal a customer wants to buy or pilot. |
