## Σκοπός

Αυτός ο φάκελος φιλοξενεί παρωχημένες, καταργημένες ή αντικατασταθείσες σελίδες wiki. Τίποτα δεν διαγράφεται — μετακινείται εδώ ώστε να διατηρείται το ιστορικό χωρίς να γεμίζει το ενεργό wiki.

## Πότε να αρχειοθετείς μια σελίδα

- Η σελίδα είναι σαφώς παρωχημένη και κανείς δεν πρόκειται να τη διορθώσει σύντομα.
- Η σελίδα αντικαταστάθηκε από νεότερη, καλύτερη σελίδα.
- Μια απόφαση αναστράφηκε και το παλαιότερο πλαίσιο δεν είναι πλέον ακριβές.

## Πώς να αρχειοθετείς μια σελίδα

1. Μετακίνησε το αρχείο από τον αρχικό φάκελο στο `/docs/wiki/Archive/`.
2. Πρόσθεσε σημείωση στην κορυφή της αρχειοθετημένης σελίδας:
   - Ημερομηνία αρχειοθέτησης
   - Λόγος αρχειοθέτησης
   - Σύνδεσμος προς αντικαθιστώσα σελίδα, αν υπάρχει
3. Αφαίρεσε τη σελίδα από το `.order` του αρχικού φακέλου.
4. Πρόσθεσε τη σελίδα στο τοπικό `.order` του Archive (προαιρετικά, για ρητή σειρά).
5. Αν η αλλαγή είναι σημαντική, κατέγραψέ την στο [Decision Log](../01-Company/Decision-Log.md).

## Τι ΔΕΝ αρχειοθετείς

- Σελίδες που είναι απλώς ημιτελείς. Βελτίωσέ τες στη θέση τους.
- Σελίδες με τις οποίες απλώς διαφωνούμε. Συζήτησε και ενημέρωσέ τες.
- Πρόσφατα meeting notes. Μένουν στο `10 Meetings`.
