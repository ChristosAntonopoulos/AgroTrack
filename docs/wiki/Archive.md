## Purpose

Outdated, deprecated or superseded wiki pages. Nothing is deleted — pages move here so the history is preserved without cluttering the active wiki.

## When to archive a page

- The page is clearly outdated and no one is going to fix it soon.
- The page has been replaced by a newer, better page.
- A decision has been reversed and the older context is no longer accurate.

## How to archive a page

1. Move the file from its original folder into `/docs/wiki/Archive/`.
2. Add a note at the top of the archived page:
   - Date archived
   - Reason for archiving
   - Link to the replacement page if any
3. Remove the page from the original folder's `.order` file.
4. Add the page to the local `.order` file in Archive (optional, for explicit ordering).
5. If the change is significant, log it in [Decision Log](./01%20Company/Decision%20Log.md).

## What NOT to archive

- Pages that are merely incomplete. Improve them in place.
- Pages we just disagree with. Discuss and update them.
- Recent meeting notes. They stay in `10 Meetings`.
