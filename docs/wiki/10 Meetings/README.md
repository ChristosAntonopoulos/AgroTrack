## How to log a new meeting

1. Copy the [Meeting Notes Template](../11%20Templates/Meeting%20Notes%20Template.md).
2. Add a section in [Meeting Notes](./Meeting%20Notes.md) (or a new child page).
3. Move any decisions to the [Decision Log](../01%20Company/Decision%20Log.md).
