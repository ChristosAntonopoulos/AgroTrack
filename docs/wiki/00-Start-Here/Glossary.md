## Σκοπός

Κοινοί όροι που χρησιμοποιούνται σε όλο το Oleachron. Προσθέστε νέες εγγραφές καθώς εξελίσσεται η ορολογία.

## Όροι

| Όρος | Ορισμός |
|---|---|
| Field | Μια καθορισμένη έκταση γης που διαχειρίζεται στο Oleachron. Έχει μέγεθος, τοποθεσία, καλλιέργεια και ιδιοκτήτη. |
| Owner | Το άτομο ή ο οργανισμός που κατέχει το field. Μπορεί να μην εργάζεται ο ίδιος στο field. |
| Producer | Το άτομο ή η ομάδα που κάνει τη δουλειά στο field. Μπορεί να διαχειρίζεται πολλά fields για πολλούς ιδιοκτήτες. |
| Agronomist | Ειδικός που συμβουλεύει για επιλογή καλλιέργειας, μεταχείριση, κύκλο ζωής και βέλτιστες πρακτικές. |
| Organisation | Ομάδα χρηστών που μοιράζονται πρόσβαση σε fields και δεδομένα (π.χ. αγρόκτημα, συνεταιρισμός, εταιρεία παραγωγής). |
| Crop | Τι καλλιεργείται σε ένα field — π.χ. ελιές, σταφύλια, σιτάρι. |
| Crop Cycle | Μία πλήρης εποχή ή κύκλος παραγωγής μιας καλλιέργειας σε συγκεκριμένο field. |
| Lifecycle Stage | Καθορισμένη φάση μέσα σε έναν κύκλο καλλιέργειας (π.χ. αδράνεια, άνθηση, καρπόδεση, συγκομιδή). |
| Field Task | Συγκεκριμένη εργασία σε ένα field (π.χ. κλάδεμα, άρδευση, μεταχείριση, συγκομιδή). |
| Field Activity | Καταγραφή κάτι που έγινε σε ένα field (π.χ. «άρδευση 4 ώρες στις 12 Μαΐου»). |
| Expense | Κόστος που καταγράφεται για field, κύκλο ή εργασία. |
| Document | Αρχείο συνημμένο σε field, κύκλο ή δραστηριότητα (π.χ. απόδειξη, φωτογραφία, πιστοποιητικό). |
| MVP | Minimum Viable Product — η μικρότερη έκδοση που μπορούμε να κυκλοφορήσουμε και να μάθουμε από αυτή. |
| Sprint | Σταθερή περίοδος (συνήθως 2 εβδομάδες) όπου η ομάδα δεσμεύεται σε ένα σύνολο εργασιών. |
| Epic / Feature / PBI / Task | Ιεραρχία στοιχείων εργασίας στο Azure DevOps. Δείτε `06 Scrum and Delivery/Work Item Structure`. |
| DoR / DoD | Definition of Ready / Definition of Done. |
| Pilot | Πραγματικός πελάτης που εκτελεί πραγματική ροή εργασίας στο Oleachron, με την ενεργή υποστήριξή μας. |
| LOI | Letter of Intent — μη δεσμευτική ένδειξη ότι ο πελάτης θέλει να αγοράσει ή να κάνει pilot. |

## Ανοιχτά ερωτήματα

- Χρησιμοποιούμε «Farm» ή «Organisation» με τους πελάτες; (Εσωτερικά χρησιμοποιούμε Organisation.)
- Διακρίνουμε «Producer» από «Operator»;
