# The Olive Lot — Logo Pack

## Use these files

- `web/logo-horizontal-ink.png` — main header on light backgrounds.
- `web/logo-horizontal-ivory.png` — main header on dark backgrounds.
- `web/logo-stacked-ink.png` — centred marketing, onboarding, and email use on light backgrounds.
- `web/logo-stacked-ivory.png` — centred marketing, onboarding, and email use on dark backgrounds.
- `mark/mark-ink.png` / `mark/mark-ivory.png` — app navigation, compact UI, and small-space brand mark.

## Website

- `web/favicon.ico` — browser favicon (16, 32, and 48 px included).
- `web/icon-192.png`, `web/icon-512.png` — web manifest/PWA icons.
- `web/apple-touch-icon.png` — iOS browser home-screen icon.
- `web/site.webmanifest` — ready-to-copy manifest reference.

## Mobile

- `mobile/app-icon-ios-1024.png` — source for the iOS App Store icon.
- `mobile/android-adaptive-foreground.png` + `mobile/android-adaptive-background.png` — Android adaptive-icon layers.
- `mobile/splash-mark-ink.png` — compact mark for a light splash screen.

## Colours

- Ink: `#1F2820`
- Ivory: `#F4F0E6`

The primary brand files are transparent PNGs. The app and browser icons use the ivory background intentionally, so they stay clear and recognizable at small sizes.
